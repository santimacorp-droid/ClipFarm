Installation & Setup Guide

ClipFarm Studio provides cross-platform desktop installers and portable packages for Windows, macOS, and Linux.

🪟 Windows 10 & 11

  1. Download ClipFarm-Studio-Setup.exe from the downloads section.
  2. Run the installer and follow the setup wizard.
  3. Or download the portable .zip package and double-click Install_ClipFarm.bat followed by Launch_ClipFarm.bat.
# Requirements: Windows 10/11 64-bit, 8GB+ RAM, NVIDIA GPU recommended for CUDA.

🍏 macOS (Apple Silicon M1/M2/M3 & Intel)

  1. Download ClipFarm-Studio-macOS.zip and extract it.
  2. Right-click Launch_ClipFarm.command and select Open.
  3. When prompted by Gatekeeper on first run, click Open Anyway in System Settings > Privacy & Security.

🐧 Ubuntu / Debian & Universal Linux

Install via the official Debian package:

sudo dpkg -i clipfarm_2.0.0_amd64.deb

Or run the Universal Self-Extracting installer:

chmod +x ClipFarm-Studio-Linux-x86_64.run && ./ClipFarm-Studio-Linux-x86_64.run

Whisper Speech Recognition Setup

ClipFarm Studio utilizes OpenAI's Whisper model architecture with word-level alignment to generate precise timestamps for kinetic captions.

Local Whisper Model Tiers

  • tiny / base: Ultra-fast, ideal for low-spec laptops with 4GB RAM.
  • small (Recommended): The sweet spot for speed and accuracy in English/Spanish/French.
  • medium / large-v3: Studio-grade transcription accuracy with multi-language nuances and technical jargon.

Hardware Acceleration Flags

In Settings > Speech Recognition, you can enable:

  • CUDA (NVIDIA): Utilizes PyTorch CUDA tensors for 10x-20x transcription speeds.
  • MPS (Metal Performance Shaders): Native Apple Silicon acceleration for Mac M-series chips.
  • CPU Multi-threading: Configurable thread counts (e.g., 4 to 16 threads) for systems without dedicated GPUs.

Optional Subtitle (.srt) Upload

Already have an accurate human transcript or YouTube SRT file? Upload it alongside your video to bypass transcription entirely and jump straight to AI viral scoring.

Configuring AI & LLM Providers

ClipFarm analyzes video transcripts to find punchy hooks and emotional highlights using large language models.

Supported Providers

  • OpenAI: GPT-4o, GPT-4o-mini (fastest & most reliable).
  • Anthropic: Claude 3.5 Sonnet, Claude 3 Haiku (superb narrative reasoning).
  • Google Gemini: Gemini 1.5 Flash / Pro (high context window).
  • Ollama (100% Offline): Run Llama 3, Mistral, or Qwen locally on your machine with 0 external network requests.
  • DeepSeek / Tongyi Qwen / Custom OpenAI-Compatible: Any vLLM, LM Studio, or local API endpoint.

Custom Scoring Thresholds

You can adjust the minimum viral threshold in Settings (default: 70/100). Higher thresholds only extract the top 10% highest-energy moments.

Kinetic Caption Customization

Subtitles are rendered via libass with custom advanced ASS subtitle event scripting.

Key Styling Parameters

  • Primary Color: Base text color (default: clean white &H00FFFFFF).
  • Highlight Color: Active spoken word highlight (vibrant yellow &H0000FFFF or cyan).
  • Border & Shadow: Heavy 3px black stroke ensures high readability on any video background.
  • Non-Overlapping Intervals: ClipFarm guarantees that $t_i^{\text{end}} = t_{i+1}^{\text{start}}$, preventing subtitle stacking bugs at millisecond zero.
  • Vertical Margin: Position captions at bottom (for TikTok UI clearance), center, or top.

9:16 Vertical Smart Framing

Convert horizontal 16:9 recordings into vertical format designed for smartphone screens:

  • 9:16 Blur Fill: Keeps the full 16:9 video centered with a dynamically blurred and zoomed background matching the video colors.
  • Smart Face Crop: Detects face coordinates and tracks the active speaker across cuts.
  • Split Screen: Displays two speakers stacked vertically for interviews and debate podcasts.

Brand Campaigns & Affiliate Mode

FAQ & Troubleshooting

FFmpeg is missing or not detected

ClipFarm bundles an FFmpeg binary in portable releases. If using system Linux, install via sudo apt install ffmpeg.

CUDA Out of Memory

If you have a 4GB or 6GB GPU, select the small or base Whisper model instead of large-v3, or lower Celery concurrency to 1 worker.

How do I batch delete old projects?

On the dashboard, click the Select button in the Projects toolbar, check the projects you wish to remove, and click Delete Selected.

Frequently Asked Questions

Is ClipFarm Studio really 100% free?

Yes! ClipFarm Studio is open-source under the MIT license. There are no paywalls, hidden export watermarks, or artificial video length limits.

Can I use it completely offline?

Absolutely. If you select local Whisper for speech recognition and local Ollama for AI scoring, not a single byte of video or audio leaves your device.

Does it support YouTube downloads?

Yes. You can paste any public YouTube or Bilibili video URL directly into the import bar to download and clip high-quality highlights automatically.

What languages are supported for captions?

Whisper supports 99+ languages including English, Spanish, Chinese, French, German, Japanese, Portuguese, and Arabic with precise word timing.
