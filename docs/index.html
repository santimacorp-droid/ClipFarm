Installation & Setup Guide

ClipFarm Studio provides cross-platform desktop installers and lightweight shell scripts for Windows, macOS, and Linux.

🪟 Windows 10 & 11

  1. Download ClipFarm-Studio-Setup.exe from the downloads section.
  2. Run the installer and follow the guided setup wizard.
  3. Or download portable .zip and run Install_ClipFarm.bat followed by Launch_ClipFarm.bat.

🍏 macOS (Apple Silicon M1/M2/M3/M4 & Intel)

  1. Download ClipFarm-Studio-macOS.zip and extract it.
  2. Double-click Launch_ClipFarm.command to start the studio.
  3. Apple Silicon Metal Performance Shaders (MPS) will be automatically detected.

🐧 Ubuntu / Debian & Universal Linux

Install via the official Debian package:

sudo dpkg -i clipfarm_2.1.0_amd64.deb

Or launch directly with shell scripts:

./run_all.sh

Faster-Whisper Speech Recognition

ClipFarm uses CTranslate2-accelerated Faster-Whisper to extract word-level timestamps without network requests.

Model Selection

  • tiny / base: Ultra-fast, ideal for low-spec laptops with 4GB RAM.
  • small (Recommended): Best balance of accuracy and speed for English, Spanish, and French.
  • medium / large-v3: Studio-grade transcription accuracy with multi-language nuances and technical jargon.

Hardware Flags

Configure acceleration in Settings > Speech Recognition:

  • CUDA: GPU tensor cores for NVIDIA RTX/GTX graphics cards.
  • MPS: Native Apple Silicon acceleration for macOS.
  • CPU Multi-threading: 4 to 16 threads for machines without dedicated GPUs.

Configuring AI & LLM Providers

ClipFarm routes transcripts through local or cloud LLMs to evaluate narrative climaxes and hook scores.

Supported Providers

  • Ollama (100% Offline): llama3.2, qwen2.5:7b, deepseek-r1:8b with zero cloud keys.
  • LM Studio: Any local GGUF loaded on http://localhost:1234/v1.
  • DeepSeek / Anthropic Claude / OpenAI / Groq: Cloud APIs for top-tier reasoning.
  • Custom OpenAI: Compatible with vLLM, LocalAI, and Together.

Kinetic Caption Customization

Subtitles are generated as Advanced SubStation Alpha (.ass) scripts and burned via hardware-accelerated libass.

Styling Presets

  • Hormozi Yellow: Bold uppercase, black stroke, vivid yellow active-word background.
  • MrBeast Pop: High-energy scale bounce animation on key action words.
  • Cyber Neon: Monospace tech look with soft cyan glow and pink highlight.
  • Clean Minimal: Editorial subtitle pill with subtle contrast.

9:16 Vertical Face Tracking

Convert horizontal 16:9 recordings into vertical format designed for TikTok, Reels, and Shorts:

  • OpenCV YuNet: Neural face detection tracks the active speaker across cuts.
  • Dynamic Blur Fill: Keeps the widescreen video centered with an ambient blurred background matching video colors.

FAQ & Troubleshooting

FFmpeg is missing or not detected

Install FFmpeg using your package manager: sudo apt install ffmpeg (Ubuntu/Debian) or brew install ffmpeg (macOS).

CUDA Out of Memory

Select the small or base Whisper model instead of large-v3, or lower Celery concurrency in .env.
